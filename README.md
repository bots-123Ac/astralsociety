## 🚀 ǫᴜɪᴄᴋ ꜱᴛᴀʀᴛ

</div>

### 📋 Prerequisites
```bash
Python 3.11+
Git
Telegram Bot Token (from @BotFather)
```

### ⚙️ Local Setup

```bash
# 1️⃣ Clone
git clone https://github.com/bots-123Ac/astralsociety.git
cd astralsociety

# 2️⃣ Virtual environment
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate

# 3️⃣ Install
pip install -r requirements.txt

# 4️⃣ Configure
cp .env.example .env
# Edit .env → add BOT_TOKEN

# 5️⃣ Run
python main.py
```

### 🚂 Deploy on Railway

[![Deploy on Railway](https://railway.app/button.svg)](https://railway.app/new/template?template=https://github.com/bots-123Ac/astralsociety)

**Steps:**
1. Fork this repo
2. New Project on [Railway](https://railway.app)
3. Deploy from GitHub → select repo
4. Add env variable: `BOT_TOKEN=your_token`
5. Deploy 🚀
