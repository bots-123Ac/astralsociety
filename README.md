<br/>

<details>
<summary><b>◆ How do I create a clone bot?</b></summary>
<br/>

Send `/clone`. Join required channels/GCs. Create a bot via @BotFather. Paste token. Done in under a minute. Limit: **1 clone per user**.

</details>

<br/>

<details>
<summary><b>◆ What if I leave a required chat?</b></summary>
<br/>

Your clone auto-disables within 10 minutes. Every user of your clone sees a friendly "temporarily disabled" message. Rejoin all required chats → auto-restores.

</details>

<br/>

<details>
<summary><b>◆ Is my bot token safe?</b></summary>
<br/>

Yes. Tokens are encrypted with **Fernet (AES-128)** before DB storage. Decrypted only in memory during clone boot. Nothing logged.

</details>

<br/>

<details>
<summary><b>◆ Why don't games work in groups?</b></summary>
<br/>

Most are DM-only to prevent spam. These work in both DM and GC: `/luckydoor`, `/defuse`, `/mission`, `/aleaderboard`.

</details>

<br/>

<details>
<summary><b>◆ Level progression formula?</b></summary>
<br/>

`XP to next = level × 1000`. So level 5 → 6 needs 5000 XP. Reaching level 50 (Astral Deity) takes ~1.27M XP total.

</details>

<br/>

<details>
<summary><b>◆ How do I earn gems?</b></summary>
<br/>

Four ways:
- `/convert 100c` — 100 coins → 1 gem
- Mystery Chest — possible reward
- Level rewards at milestones (3, 6, 11, 16...)
- Premium benefits

</details>
