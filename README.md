### <i>— A note from the editors —</i>

</div>

<br/>

<div align="center" style="max-width: 720px; margin: 0 auto;">

<p><i>
There's a particular kind of Telegram bot that just works. It shows up quietly, does its job, doesn't beg for attention, and somehow you find yourself opening it every day. Astral Empire was built with that intent.

It began as a study-bot for a small Telegram group. Then someone asked if it could handle a quiz. Then games. Then an economy. Then — as these things tend to go — someone asked the impossible question: <b>"Can I have my own version of this?"</b>

The Clone System is our answer. Every qualified user can spawn their own fully-featured instance of Astral Empire under their own bot token, with their own brand, their own admin panel, their own data. The features are identical. The identity is yours.

What follows is a field guide to what's inside.
</i></p>

</div>

<div align="center">

<table>
<tr>
<td align="center" width="33%" valign="top" style="padding: 30px;">

<h3>◆</h3>

<h4><b>The premise</b></h4>

<p><sub>
Most bots are single-instance. One bot, one owner, one community. We thought that was a design flaw. Why shouldn't a user be able to spin up their own branded instance using the same powerful backend?
</sub></p>

</td>
<td align="center" width="33%" valign="top" style="padding: 30px;">

<h3>◆</h3>

<h4><b>The execution</b></h4>

<p><sub>
Every clone runs its own <code>Bot</code>, <code>Dispatcher</code>, and <code>Router</code> set — same codebase, separate context. Tokens are encrypted with AES-128 via Fernet before hitting the database. A middleware re-verifies the owner's required-chat membership every ten minutes.
</sub></p>

</td>
<td align="center" width="33%" valign="top" style="padding: 30px;">

<h3>◆</h3>

<h4><b>The result</b></h4>

<p><sub>
Today, up to twenty users can run their own Astral Empire under their own brand. Every game works. Every leaderboard works. Every study feature works. The only thing that changes is who's in charge.
</sub></p>

</td>
</tr>
</table>

</h1>

<p><sub><i>The six we get most often.</i></sub></p>

</div>

<br/><br/>

<table align="center" width="85%">

<tr>
<td width="40%" valign="top" style="padding: 20px;">

### <b>Q. How do I create a clone?</b>

</td>
<td width="60%" valign="top" style="padding: 20px;">

Send <code>/clone</code>. Join required channels and groups. Create a bot via <b>@BotFather</b>. Paste the token. Done in under sixty seconds. Limit: one clone per user.

</td>
</tr>

<tr>
<td width="40%" valign="top" style="padding: 20px;">

### <b>Q. What if I leave a required channel?</b>

</td>
<td width="60%" valign="top" style="padding: 20px;">

Your clone auto-disables. Every ten minutes the system re-verifies your membership. If you've left any required chat, the clone shows a "temporarily disabled" message to users. Rejoin, and it auto-restores.

</td>
</tr>

<tr>
<td width="40%" valign="top" style="padding: 20px;">

### <b>Q. Is my bot token safe?</b>

</td>
<td width="60%" valign="top" style="padding: 20px;">

Tokens are encrypted with <b>Fernet (AES-128)</b> before they touch the database. They're only decrypted in memory when the clone is starting. Nothing is logged.

</td>
</tr>

<tr>
<td width="40%" valign="top" style="padding: 20px;">

### <b>Q. Why won't games work in groups?</b>

</td>
<td width="60%" valign="top" style="padding: 20px;">

Most games are DM-only to prevent spam. These work in both DM and GC: <code>/luckydoor</code>, <code>/defuse</code>, <code>/mission</code>, <code>/aleaderboard</code>.

</td>
</tr>

<tr>
<td width="40%" valign="top" style="padding: 20px;">

### <b>Q. What's the level progression formula?</b>

</td>
<td width="60%" valign="top" style="padding: 20px;">

XP required for the next level = current level × 1000. So level 5 → 6 needs 5000 XP. Cumulative across the 50 levels, reaching Astral Deity takes roughly 1.27 million XP.

</td>
</tr>

<tr>
<td width="40%" valign="top" style="padding: 20px;">

### <b>Q. How do I earn gems?</b>

</td>
<td width="60%" valign="top" style="padding: 20px;">

Four ways: <code>/convert 100c</code> exchanges 100 coins for 1 gem. Mystery Chest gives gems as a possible reward. Level rewards at certain thresholds. Premium benefits.

</td>
</tr>

</table>
