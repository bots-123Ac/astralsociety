## 🚀 ǫᴜɪᴄᴋ sᴛᴀʀᴛ

</div>

### 📋 Prerequisites
```bash
Python 3.11+
Git
Telegram Bot Token (from @BotFather)
```

### ⚙️ Local Setup

```bash
# 1️⃣ Clone the repository
git clone https://github.com/bots-123Ac/astralsociety.git
cd astralsociety

# 2️⃣ Create virtual environment
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate

# 3️⃣ Install dependencies
pip install -r requirements.txt

# 4️⃣ Configure environment
cp .env.example .env
# Edit .env and add your BOT_TOKEN

# 5️⃣ Run the bot
python main.py
```

### 🚂 Deploy on Railway

[![Deploy on Railway](https://railway.app/button.svg)](https://railway.app/new/template?template=https://github.com/bots-123Ac/astralsociety)

**Steps:**
1. Fork this repo
2. Go to [Railway](https://railway.app)
3. New Project → Deploy from GitHub
4. Add environment variable: `BOT_TOKEN=your_token`
5. Deploy 🚀
